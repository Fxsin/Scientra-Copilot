# Config

## Purpose

Configuration files for all Scientra Copilot engines and the workflow runner.

## Files

| File | Purpose |
|------|---------|
| `workflow_config.yaml` | Workflow runner configuration |
| `grobid.yaml` | GROBID server settings |
| `embedding.yaml` | Embedding model and LanceDB settings |
| `tag_ontology.yaml` | Tag ontology definition |
| `tag_dictionary.yaml` | Tag dictionary for matching |

## User Editing

**Yes** — configure paths, API endpoints, and model settings before first run. See each file for inline documentation.

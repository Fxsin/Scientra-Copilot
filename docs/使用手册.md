# Scientra Copilot 使用手册

> **版本:** v1.0-alpha — Evidence-Oriented Literature Agent Chat

## 快速开始

### 1. 环境要求
- Python 3.11+
- Docker（用于 GROBID PDF 解析）
- Node.js 18+（用于 Web 前端）

### 2. 启动服务

```bash
# 一键启动（API + Web）
python Scripts/dev_restart.py

# 或分别启动：
python -m scientra.server          # API: http://127.0.0.1:8710
cd web && npm run dev              # Web: http://127.0.0.1:3000
```

### 3. 导入文献

```bash
# 将 PDF 放入 00_Inbox/
python workflow.py run
```

### 4. 配置 LLM API（推荐，用于 AI 对话）

```bash
python Scripts/setup_llm.py
```

选择 DeepSeek 或 Anthropic，粘贴 API key 即可。Key 保存在 `Config/llm_config.yaml`（不会上传到 git）。

## 核心功能

### 💬 AI 文献对话（v1.0-alpha）

访问 `http://127.0.0.1:3000/chat`，直接对文献库提问。

**四类核心查询，系统自动识别意图：**

| 查询类型 | 示例问题 | 输出格式 |
|---|---|---|
| **claim_query** | What claims need stronger evidence? | 结构化 Claim → Evidence → Missing evidence → Sources |
| **research_gap_query** | What research gaps can be inferred? | Evidence-based gaps + Inferred gaps |
| **method_query** | What methods are commonly used? | 按 5 大类分组（分子/蛋白/生测/显微/计算） |
| **result_query** | Which results are most frequently reported? | 结果分类 + 证据强度评估 |

**三种回答模式：**
| 模式 | 说明 |
|---|---|
| Auto（推荐，默认） | 有 API key 时用 LLM 生成综合回答；否则展示检索证据 |
| LLM synthesis | 强制使用 LLM API 生成学术化引用回答 |
| Evidence-only | 不调用 LLM，直接展示结构化检索证据 |

**安全特性：**
- 自动过滤出版商免责声明、版权声明、数据可用性声明
- 杜绝 `[object Object]` 等代码污染
- 所有回答必须带 `[Ref:N]` 可追溯引用
- API key 绝不暴露到前端

**论文页面提问：** 在 `/paper/{id}` 页面，展开 "Ask this paper" 卡片，可直接对当前论文提问。

### 📊 文献数据处理

系统自动将 PDF 转化为多层次结构化数据：

```
PDF → 元数据 → 摘要 → 证据提取 → 数据资产化 → 向量嵌入 → 智能检索
```

**数据资产化层包含：**
- 章节文本（sections）
- 方法（methods）
- 结果（results）
- 实体（entities：蛋白质、基因、物种等）
- 论断（claims）
- 证据链接（evidence links）
- 图表信息（figures：标题、类型、引用句）
- Agent 可调用的知识片段（agent chunks）

### 🔍 检索功能

| 接口 | 说明 |
|---|---|
| `/query/assets` | 搜索质量过滤后的资产片段 |
| `/query/evidence` | 搜索证据片段 |
| 支持按类型过滤 | section / method / result / claim / figure |

### 📈 分析页面

| 页面 | 功能 |
|---|---|
| Research Map | 研究主题图谱，支持 Facet/Topic 视图 |
| Hotspots | 热门话题、热点论文、新兴方向 |
| Research Gaps | 自动检测研究空白 |
| Knowledge Network | 论文-方法-发现关系网络 |
| Report | 自动生成的文献库智能报告 |

## LLM API 配置详解

### 支持的 LLM 提供商

| 提供商 | 模型 | 获取 Key |
|---|---|---|
| DeepSeek | deepseek-chat | https://platform.deepseek.com |
| Anthropic | claude-sonnet-4-6 | https://console.anthropic.com |

### 配置方式

**方式一：交互式设置（推荐）**
```bash
python Scripts/setup_llm.py
```

**方式二：环境变量**
```powershell
# Windows PowerShell
$env:DEEPSEEK_API_KEY = "sk-..."
# 或
setx DEEPSEEK_API_KEY "sk-..."
```

```bash
# Linux / macOS
export DEEPSEEK_API_KEY="sk-..."
```

### 安全说明

- API key 只保存在后端，**绝不会**暴露到前端
- `Config/llm_config.yaml` 已加入 `.gitignore`
- 不要在 `NEXT_PUBLIC_*` 环境变量中存储 key

## 常见问题

**Q: Chat 显示 "LLM API is not configured"？**
A: 运行 `python Scripts/setup_llm.py` 配置 API key，然后重启后端。

**Q: 如何切换到 Evidence-only 模式？**
A: 在 Chat 页面点击 Advanced Options → Answer Mode → 选择 Evidence-only。

**Q: API key 会被上传到 GitHub 吗？**
A: 不会。`Config/llm_config.yaml` 已加入 `.gitignore`。

**Q: 支持哪些文献格式？**
A: 目前支持 PDF 格式，通过 GROBID 解析。

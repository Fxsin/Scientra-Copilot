## Summary Engine — Agent Mode vs Direct API Mode

Scientra Copilot supports two summary generation modes. The default is **Agent Mode**.

### Agent Mode (Default)

When `summary.mode: agent` (default in `Config/workflow_config.yaml`):

- Summaries are generated via the configured LLM agent (Claude Code Agent or compatible endpoint).
- **No `DEEPSEEK_API_KEY` is required.**
- The system checks for API keys in this order: `ANTHROPIC_API_KEY` → `DEEPSEEK_API_KEY` → `SCIENTRA_API_KEY`.
- If NO API key is available (e.g., running inside Claude Code without explicit keys), prompts are written to `03_Summary/agent_prompts/` and marked `pending_agent` for resolution by the Claude Code Agent session.
- The workflow is **never blocked** by a missing API key in agent mode.

### Direct API Mode (Legacy)

When `summary.mode: direct_api`:

- Summaries are generated by calling the DeepSeek API directly via raw HTTP.
- **`DEEPSEEK_API_KEY` is required.**
- Missing API key blocks summary generation (except when valid cache exists).

### Switching Modes

```yaml
# Config/workflow_config.yaml
steps:
  summary:
    mode: "agent"          # or "direct_api"
    fallback_mode: "direct_api"
```

See `docs/Summary_Agent_Mode.md` for detailed documentation.

## First Deployment

1. Create Python 3.11+ environment.
2. Install Python dependencies: `pip install -r requirements.txt`
3. Install scientra package: `pip install -e .`
4. Install Docker Desktop.
5. Start GROBID container: `python Scripts/setup_grobid.py`
6. Configure `Config/grobid.yaml` (optional — defaults work out of the box).
7. (Optional) Set `ANTHROPIC_API_KEY` or `DEEPSEEK_API_KEY` for automatic summary generation.
   - Agent Mode (default): no API key required in Claude Code; prompts resolved by Claude Code Agent.
   - Direct API Mode: requires `DEEPSEEK_API_KEY`.
8. Run `python Scripts/setup_check.py`.
9. Run a dry workflow: `python Scripts/run_workflow.py --input 01_PDF/batch_5 --dry-run`.
10. Run real workflow: `python Scripts/run_workflow.py --input 01_PDF/batch_5`.

## Troubleshooting

- GROBID unavailable: run `python Scripts/ensure_grobid.py --json`.
- Summary blocked (direct_api mode): verify `DEEPSEEK_API_KEY` or switch to agent mode (`summary.mode: agent`).
- Summary pending (agent mode): prompts written to `03_Summary/agent_prompts/`; resolved by Claude Code Agent.
- Summary blocked (agent mode, cache-only): run without `--cache-only` or set an API key.
- Embedding slow: confirm BGE-M3 is cached and consider GPU.
- LanceDB missing tables: rerun P6 embedding real-run or `run_workflow.py` without `--skip-embedding`.
- Query API not searchable: check LanceDB table counts and `python Scripts/system_check.py`.

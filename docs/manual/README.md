## Generation

The file placement guide is generated by:

```bash
python Scripts/generate_file_placement_guide.py
```

This script generates both `.md` and `.docx` versions. It does **not** overwrite existing files — if a file with the same name exists, a timestamp is appended.

## User Editing

**No** — these files are auto-generated. Edit `Scripts/generate_file_placement_guide.py` and re-run to update.
